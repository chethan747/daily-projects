# daily-projects

One small build every day — Python, AI/ML, JavaScript, Java and web experiments. Each folder is a complete, runnable mini project with its own README.

| Day | Project | What it is |

| 001 | [neural-net-scratch](day-001-neural-net-scratch/) | Feedforward neural network from scratch in pure Python (no numpy) — XOR 4/4, 2D blobs 99% |
| 002 | [markdown-toc](day-002-markdown-toc/) | Tiny Node.js CLI that builds a clickable table of contents from a Markdown file's headings |
| 003 | [ascii-progress-bar](day-003-ascii-progress-bar/) | Tiny dependency-free ASCII progress bar for Node.js terminal scripts |
| 004 | [tic-tac-toe-minimax](day-004-tic-tac-toe-minimax/) | Tic-tac-toe with an unbeatable minimax AI (playable + AI-vs-AI demo) |
| 005 | [password-strength-meter](day-005-password-strength-meter/) | Password strength scorer: one-function JS meter with entropy estimate and plain-language tips |
| 006 | [morse-code-cli](day-006-morse-code-cli/) | Morse code encoder/decoder CLI in Node.js |
| 007 | [gradient-palette-generator](day-007-gradient-palette-generator/) | Browser-based colour palette generator: tints, shades, harmony swatches, copy-on-click hex codes |
| 008 | [heatmap-calendar](day-008-heatmap-calendar/) | GitHub-style contribution heatmap generator (Python + matplotlib) |
| 009 | [csv-column-stats](day-009-csv-column-stats/) | Tiny CLI that prints per-column stats and ASCII charts for any CSV file |
